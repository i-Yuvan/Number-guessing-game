***Number Guessing Game***

A simple game where the player guesses a
random number between 1 and 100.

---Features
1. Random number generation
2. Hints for high and low guesses
3. Counts attempts
4. Handles invalid input

---Requirements
Python Language

---How to Run

```bash
python guessing_game.py
```

---Concepts Used
Random numbers, loops, conditions,
user input and exception handling.
