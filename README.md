# Python Number Guessing Game

A simple game where the player guesses a
random number between 1 and 100.

## Features
- Random number generation
- Hints for high and low guesses
- Counts attempts
- Handles invalid input

## Requirements
Python 3

## How to Run
```bash
python guessing_game.py
```

## Concepts Practised
Random numbers, loops, conditions,
user input and exception handling.
